# NewTrade V2 protocol specification

The executable specification is the Solidity source and
[`src/INewTradeEscrowV2.sol`](src/INewTradeEscrowV2.sol), together with the vault interface
[`src/interfaces/INewTradeVaultV2.sol`](src/interfaces/INewTradeVaultV2.sol). The architecture
and trust boundaries are summarized in [`ARCHITECTURE.md`](ARCHITECTURE.md). ABI-, event- and
storage-affecting changes are listed in [`CHANGELOG.md`](CHANGELOG.md), and each live
deployment is recorded in [`deployments/`](deployments/README.md).
